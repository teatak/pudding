# Pudding Microsoft Store English listing

## Description

Pudding is a desktop AI assistant for everyday work and coding. Connect your chosen models to work across independent conversations, explore and edit local project files, create documents and tables, and schedule recurring tasks.

Key features

• Your models, separate conversations: configure model providers, models and API keys, with an independent history for each task.
• Coding and project files: read, search and edit local files, explore code and review Git diffs.
• Documents and tables: create and organize documents, tables and interactive widgets in Studio, with editing and version history.
• Scheduled tasks: arrange one-time or recurring AI work and review execution history. Pudding must stay running and the device must stay awake.
• Plugins and MCP: connect the tools and services you choose.

Pudding uses live generative AI. Output depends on the selected model and service and may be inaccurate. Review results before relying on them or executing actions. Custom models are supported; the app does not apply a single content filter across all providers.

Conversation history and configuration are stored on your device. When you use an online model or connected service, submitted prompts, attachments and relevant tool results may be sent to that service and are governed by its terms and privacy policy.

Pudding is free to use. Third-party models and services may charge separately and require your own service configuration or API key. Windows terminal features require PowerShell 7; Git and Go features require their respective tools.

Supports Windows desktop on x64 and ARM64. The Windows version does not currently include local computer use, camera capture or voice dictation.

To report inappropriate AI output or product issues, use Help > Report an Issue in the app. Do not include API keys, tokens or private content in public reports.
