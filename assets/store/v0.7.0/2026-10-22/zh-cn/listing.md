# Pudding Microsoft Store 中文文案

## 商店产品名称

Pudding

## 说明

Pudding 是一个面向日常工作和编程的桌面 AI 助手。连接你选择的模型，用多个独立会话协助编程、整理本地项目文件、创建文档和表格，并安排定时任务。

主要功能

• 自选模型与多会话：配置模型提供商、模型和 API 密钥，为不同任务保留独立的对话历史。
• 编程与项目文件：查看、搜索和编辑本地项目文件，结合 AI 阅读代码、修改内容，并审阅 Git 差异。
• 文档与表格创作：在 Studio 创建和整理文档、表格与交互小组件，继续编辑和查看版本历史。
• 定时任务：安排一次性或重复的 AI 工作，保留执行记录；应用需保持运行，设备需处于唤醒状态。
• 插件与 MCP：连接你选择的工具和服务，扩展工作流程。

Pudding 集成生成式 AI。输出取决于你选择的模型和服务，可能存在错误，请在使用或执行前检查结果。应用支持自定义模型，没有统一的应用级内容过滤。

对话历史和配置保存在本机。使用在线模型或连接服务时，你提交的提示词、附件及相关工具结果可能发送至所选服务，并适用该服务的条款和隐私策略。

Pudding 免费使用；第三方模型和服务可能另行收费，需要你自行配置有效的服务或 API 密钥。Windows 终端命令功能需要另行安装 PowerShell 7；Git 和 Go 相关功能分别需要对应工具。

支持 Windows 桌面 x64 和 ARM64。Windows 版暂不支持本机电脑操作、相机和语音听写。

如需报告不当 AI 内容或产品问题，可使用应用内“帮助 → 报告问题”。请勿在公开报告中包含 API 密钥、令牌或私人内容。

## 简短描述

连接自选 AI 模型，协助编程、处理本地项目文件、创建文档与表格，并安排定时任务。对话保存在本机，模型服务由你配置。

## 产品功能

- 自选 AI 模型与 API 密钥，多会话独立管理任务
- 协助编程，查看、搜索和编辑项目文件，审阅 Git 差异
- Studio 文档、表格与交互小组件创作，支持版本历史
- 一次性和重复定时任务，保留执行记录
- 插件、技能与 MCP 工具，扩展常用工作流程

## 此版本的新增功能

0.7.0
• 按会话明确选择插件连接，改善账号信息展示与会话之间的连接隔离。
• Web 搜索与抓取改用标准连接，支持 DeepSeek，并兼容已有配置。
• 改善 Widget 校验与错误详情、文件导出，以及导入导出的进度、取消和失败反馈。
• 分支会话共享 Widget 连接与 Studio 上下文，优化 Studio 导航和会话选择。
• 优化上下文压缩、输入准备、重试和对话进度展示。
• 改善 Microsoft Store 更新操作及取消后的恢复。

升级提示：本地数据库从 v47 升级到 v48，升级前自动备份。旧版无法直接打开升级后的数据库；降级前请恢复对应备份。需要插件账号的会话现在要求明确选择连接。
